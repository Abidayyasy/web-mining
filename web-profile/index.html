Project Web Mining

Crawling detik.com — Finance & Olahraga (tugas PPWA)

crawler_detik.ipynb

100/tema → 200 artikel

Crawler mengambil berita dari finance.detik.com dan sport.detik.com via requests + BeautifulSoup (discovery /d-\d+/) dan trafilatura untuk extract isi_berita bersih. Output detik_berita.csv dengan 3 kolom Excel-friendly: A=id, B=isi_berita, C=tema (sep=";").

  • Target 2 tema × 100 = 200 artikel, ThreadPool + tqdm + log OK | judul...
  • Fallback pagination /indeks?page=2..15 biar 100/tema tercapai
  • CSV 1 baris = 1 artikel, 1 cell = 1 kolom (tanpa \n/; di isi)
